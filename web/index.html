Tagging your usage

          

            Any CC_ variable in a Claude Code settings file's env becomes a tag on your usage,
            to filter and group by here. Put them in a repository's .claude/settings.json (for everyone
            working in it) or .claude/settings.local.json (just you):
          

          
{ "env": { "CC_PROJECT": "apollo", "CC_TEAM": "payments" } }

          

            For one session, put it on the command line: CC_PROJECT=apollo claude. In a repository that
            sets its own, the repository's wins, so override it with
            claude --settings '{"env": {"CC_PROJECT": "apollo"}}'. Without any, your usage has no tags.
          

          
What it changes

          

            Two sections in ~/.aws/config, the Bedrock and telemetry settings in
            ~/.claude/settings.json (the rest of that file stays as it is), and a small helper in
            ~/.claude/cc-bedrock/. Telemetry is counts, costs, models and tool names: never your prompts,
            Claude's answers or your code.
          

          

            
            The same settings for /Library/Application Support/ClaudeCode/managed-settings.json; see the
              README.
